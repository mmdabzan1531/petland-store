# پت‌لند — فروشگاه نمونه حیوانات خانگی

یک فروشگاه نمایشی فارسی و راست‌چین با Next.js، React، TypeScript و CSS.

## امکانات
- ۵۰ محصول فرضی در ۶ دسته‌بندی
- جستجو و فیلتر دسته‌بندی
- سبد خرید با افزایش/کاهش تعداد و ذخیره در localStorage
- فرم ورود و ثبت‌نام نمایشی
- بخش معرفی فروشگاه و امتیازدهی
- طراحی واکنش‌گرا برای موبایل و دسکتاپ

## اجرا
نیازمند Node.js نسخه ۱۸ یا بالاتر:

```bash
npm install
npm run dev
```

سپس آدرس `http://localhost:3000` را باز کنید.

## نکته مهم
این نسخه فرانت‌اند نمایشی است. ثبت‌نام واقعی، احراز هویت امن، دیتابیس، پنل مدیریت، درگاه پرداخت و ثبت سفارش سمت سرور هنوز پیاده‌سازی نشده‌اند. قیمت‌ها و تصاویر نمونه‌اند و تصاویر از Unsplash بارگذاری می‌شوند.
