# پت‌لند

- `/` صفحه اصلی: عکس مستطیلی گربه + دکمه «خرید»؛ پایین‌تر فقط درباره سایت
- `/shop` فروشگاه: عکس مستطیلی گربه، تخفیف‌های ویژه (دسته‌بندی‌شده)، دسته‌بندی کالاها، همه کالاها (پرفروش‌ها اول)
- منوی کشویی از سمت راست (حدود ۱/۴ صفحه) با دکمه سه‌خط بالا راست — فایل `components/SideMenu.tsx`

## اجرا
npm install
npm run dev

## ساختار
app/page.tsx · app/shop/page.tsx · app/layout.tsx · app/globals.css · components/SideMenu.tsx · data/products.json
