# پت‌لند — نسخه به‌روزشده

## امکانات
- صفحه اصلی سبز با معرفی پت‌شاپ
- منوی سه‌خطی در بالای سمت راست
- صفحه جداگانه فروشگاه در مسیر `/shop`
- نمایش ۵۰ محصول فرضی با جستجو و دسته‌بندی
- سبد خرید نمایشی
- بخش پرفروش‌ترین‌ها بر اساس تعداد فروش فرضی هر کالا
- بخش تخفیف‌های ویژه با درصد تخفیف و قیمت قبلی/جدید
- بدون دکمه یا بخش لایک محصول

## اجرا
```bash
npm install
npm run dev
```

## تنظیمات Render
- Root Directory: خالی
- Build Command: `npm install && npm run build`
- Start Command: `npm start`
- Runtime: Node

تعداد فروش، قیمت‌ها و تخفیف‌ها در این نسخه نمایشی و فرضی هستند. درگاه پرداخت و دیتابیس واقعی متصل نیستند.
